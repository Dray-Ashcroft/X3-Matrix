<h1 align="center"><strong>🧬 Xtrematrix Prejudix</strong></h1>

<h3 align="center"><em>Interactive Natural Selection & Evolution Simulator</em></h3>

>Xtrematrix Prejudix is an interactive simulator focussed on variation, natural selection and evolutionary adaptation.

🏞️ ["Explore the Matrix"](https://xtrematrix.stark-kodex.workers.dev)

✨ **Features**

🔸 🧬 Genetic variation and trait differences
🔸 🦅 Predator–prey interactions
🔸 🌱 Environmental selection pressures
🔸 🐇 Adaptation across generations
🔸 🔬 Interactive, educational simulations

---

🧑🏻‍💻 **Technology**

🔸HTML · CSS · JavaScript · Three.js · Supabase · Cloudflare Workers.
